# Site map

**In plain words:** the website has a single page. Everything else is behind-the-scenes "API" addresses that
the page (or Telegram, or Vercel's daily timer) calls. All of them except the status check need the access
key.

## Pages

| Path | What it shows |
|---|---|
| `/` | Portrait phone: the **avatar screen** (Jeannie full height, her words as subtitles, buttons to switch to the HUD, pick an outfit (wardrobe) and hold to talk). Elsewhere: the **HUD** (chat terminal, metrics, memory panel, camera, smart-home grid); `1 \| 2` in the header switches between the classic HUD and Jeannie standing in the left frame (with its own wardrobe button). A choice made on a device is remembered there. |
| `/manifest.webmanifest` | PWA manifest (generated by `src/app/manifest.ts`) |
| `/sw.js`, `/avatar/*`, `/icons/*` | Static files from `public/` |

The QA emote picker shows on every Vercel preview, and on a local build with `?debug=emotes`; never on production.

## API routes

"Key" means `JEANNIE_ACCESS_KEY`, sent as `x-jeannie-key: <key>` or `Authorization: Bearer <key>`
(`src/lib/auth.ts`). When the key is not configured, routes marked "key" are open, but nothing is *trusted*:
memory recall and live Hangeul data need a proven secret.

| Route | Method | Runtime | Auth | Does | Calls |
|---|---|---|---|---|---|
| `/api/status` | GET | Edge | **open** | Booleans and model names: is a key required, which LLM, memory/search/voice/Telegram configured, Hangeul live or mock | `env.ts` |
| `/api/chat` | POST | Edge | key | Body `{messages[≤50], image?, lang?}` (image ≤3 MB data URL). Streams the reply as text; headers carry agent, language, provider, honorific, sources | `agents/orchestrator.ts` |
| `/api/session` | GET | Edge | key | `?awayMs=` → the opening Korean greeting (model-written, template fallback in ~4 s) | `agents/greeting.ts` |
| `/api/search` | GET `?q=` / POST `{query, maxResults?}` | Edge | key | Live web search results | `agents/search-agent.ts` |
| `/api/tts` | POST `{text ≤2000, lang?}` | Node | key | MP3 of the text (ElevenLabs → Edge TTS); 503 tells the page to use browser speech | `agents/tts-engine.ts` |
| `/api/memory` | GET / POST / PATCH `?id=` / DELETE `?id=` | Node | key **required** (403 if no key is configured) | List, upload (`{name, content, pinned?}` or multipart, ≤1 MB `.md`/`.jsonl`), pin, delete notes | `memory/store.ts` |
| `/api/hangeul` | GET `?action=report\|status`, POST `{action: report\|status\|notify}` | Node | key, or `CRON_SECRET` | Hangeul report/status; bare GET from the cron and `notify` send the report to the Telegram admin chat | `agents/hangeul-bridge.ts`, `telegram.ts` |
| `/api/telegram/webhook` | POST | Node | `x-telegram-bot-api-secret-token` must equal `TELEGRAM_WEBHOOK_SECRET` (refused if unset) | Handles Telegram updates; only the admin chat gets answers | `telegram.ts` |

Errors are JSON `{error, code}` with a 4xx/5xx status (`src/lib/utils.ts` `errorResponse`).
